Modelos 3D del configurador CDP Customs.

Coloca aqui el modelo real como `volante.glb` o cambia `MODEL_URL` en
`public/assets/js/configurator.js`.

Nombres recomendados de meshes dentro del GLB:
- aro
- agarres_left / agarres_right
- centro
- costuras
- marcador_superior
- levas_left / levas_right
- pantalla_rpm
- molduras
- logo

Si el archivo no existe, el configurador carga un volante 3D procedural de demo
con la misma estructura logica de piezas para no bloquear el desarrollo.
